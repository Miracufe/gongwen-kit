# gongwen-kit

面向党政机关、央国企日常公文场景的**生成与机检工具包**：按 GB/T 9704 等国标生成标准
Word（.docx）公文——通知、报告、请示、函、纪要、管理办法、条例——出稿即机检。

免费开源、本地运行、文件进文件出。

> v0.2.0（2026-10-13）：补信函格式。五份样张、三道出稿机检与真实件回归全部核过。

## 项目原则

1. **适用范围与依据**：面向党政机关、央国企日常使用的公文体系；依据 GB/T 9704—2012、
   GB/T 15834、GB/T 15835、GB/T 1.1、GB/T 8170、GF 1001 与《党政机关公文处理工作条例》
   （中办发〔2012〕14 号）。党政机关适用，其他机关和单位参照执行；发文机关标志、机关代字、
   发文字号等为可配置参数。体式两种（行文、条文），日常文种多数走行文体。
2. **目标**：文件进、文件出；免费开源、可审计；工具链本地运行、安装后零网络。
   全链路隐私取决于模型部署方式——配内网／本地模型可全链路不出本机。
3. **内容责任边界**：工具不校验、不背书内容的正确性与政治表述，判断和责任归写稿人；
   工具只保证形制合规与信息层保真（同一名称一致、数字与条件保真）。
4. **对标与运行平台**：合规以国标为唯一基准，兼容以微软 Office 与 WPS（Windows）为
   验收平台；增量适配——输出标准 docx，用户继续在 Office／WPS 里编辑、套打、转
   PDF／OFD。信创环境留观察位。

## 能力

- **两种体式**：行文体（报告、请示、函、纪要等）与条文体（管理办法、条例，章条全文连号）
- **版头**：发文机关标志（单个与联合行文）、发文字号、签发人（上行文，回行对齐）、
  红色分隔线；数字红头与预印套打两种形态；份号／密级／紧急程度可选
- **信函格式**（GB/T 9704 10.1）：标志距上页边 30 mm、上粗下细与上细下粗两条 170 mm 红色双线、
  发文字号居右、首页不印页码、版记只留抄送；九项尺寸经 Word 渲染量测
- **版记**：抄送机关、印发机关和印发日期、三条分隔线，浮动锚定在版心底部
- **出稿即机检**：结构 → XML → 体例（GB/T 9704）→ 数字自洽 → 文风（规范层拦、风格层提示），
  每条检查对应国标条款；机检输出可存文件，作为合规凭据
- 全部纯 Node：没有 Python、没有 unzip、没有 Word 依赖，Windows 上开箱即跑

## 安装

```bash
git clone https://github.com/imhuhe/gongwen-kit.git && cd gongwen-kit
npm install
```

当作 agent skill 用（Claude Code 与 OpenCode 读同一目录约定；Codex 换 `~/.codex/skills`）：

```bash
ln -s "$(pwd)" ~/.claude/skills/gongwen-kit
```

## 用法

```bash
node templates/complete.js      # 要素全览：所有构件与格式摆在一份里
node templates/notice.js        # 带完整版头与版记的通知（两行标题回行）
node templates/gongwen-qingshi.js   # 请示（上行文，含签发人）
node templates/gongwen-guanli.js    # 管理办法（条文体，四层）
node templates/xinhan.js            # 函（信函格式）
```

写自己的公文：起一份稿源脚本，在里面的构件调用中写正文。

```bash
node tools/new-doc.js --form wen --out 我的稿子.js
node 我的稿子.js                # 出稿；写盘后自动跑机检，非零退出即没过
```

体检别的文件（手写的稿子也可以）：

```bash
node checks/check-doc.js  某文件.docx --strict    # 体例与语言
node checks/check-num.js  某文件.docx --strict    # 数据表数字自洽
node checks/check-style.js 某文件.docx --strict   # 文风
```

导出 PDF 后核字体与版面（可选，需要 PyMuPDF）：

```bash
~/.venvs/pdf/bin/python3 tools/check-pdf.py 导出件.pdf
```

## 文档

| 文件 | 内容 |
|---|---|
| `docs/依据.md` | 引用的国标与条款对照 |
| `docs/版式.md` | 硬指标、校准值、踩过的坑——改版式前必读 |
| `docs/文风.md` | 两层判据、词表校准办法、怎么加自己的词 |
| `docs/字体.md` | 国标用字对照、方正小标宋授权与替代、字体验证 |
| `SKILL.md` | 给 agent 的入口（工作流与要素速查） |

## 边界（不做）

内容与政治表述校对（责任归写稿人）；命令（令）格式；OFD 与电子公文交换；
印章图像与数字签章（只预留位置）；公文流转审批；云端服务；AI 写作语料。
